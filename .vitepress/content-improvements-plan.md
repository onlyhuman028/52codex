## 共同规则

- 文章 frontmatter 使用 status: published / improving / coming-soon，对应已发布、待完善、待上线。已有正文不改写；现有跳转占位页标为待上线，明确缺少素材的案例标为待完善。
- 使用 VitePress 自带内容加载器，在构建时解析元数据。首页、导航、栏目总览、推荐、robots 与 sitemap 使用相同状态规则。待完善可阅读但不参与下一篇推荐和搜索引擎收录；待上线保留标识并引导到占位页。
- 首页保留原有精选位置，分类、封面和入口来自文章元数据。GitHub 使用已核对的 origin，投稿使用站内已有联系邮箱。阅读时间估算，额度仅展示带来源说明的实际记录。
- 完整历史失败后每十分钟重试；热帖回退区分空结果、缺少配置和来源失败，不泄露上游响应或密钥。
- 长文章使用页面标题生成目录；导航支持键盘与关闭后焦点恢复；复制失败可重试；审核操作期间禁用重复操作。
- 留言新增采用独立记录，兼容旧数组，不自动删除旧记录。管理操作保存独立字段，避免审核与回复互相覆盖；分页遵循 KV 游标，公开接口只返回已审核内容。

2. 动态恢复：增加降级后恢复完整历史、失败原因与缓存回退测试，再修改加载器及接口。
