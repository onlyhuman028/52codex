# 谷歌账号（Gmail）登录、安全、养号全教程

这篇教程整理自[赵赵AI小窝的原文](https://zzaibox.cn/user/help/article.16)，并按普通用户可执行的登录与安全流程重新编排。

本文只适用于你本人创建、持有或获得合法授权的账号。不要把密码、验证码、备用码或 2FA 密钥交给陌生人，也不要使用所谓的“代过验证”服务。

## 一、登录前先准备什么

先确认你手里有哪些登录信息：

- Gmail 邮箱地址
- 当前密码
- 恢复邮箱或恢复手机号
- 两步验证方式，例如 Google 提示、身份验证器或备用码

只在 [Google 官方登录页](https://accounts.google.com/)输入密码和验证码。

如果账号来自单位或学校，部分设置由管理员控制，个人账号的操作步骤可能不适用。

## 二、用账号和密码登录

1. 打开 [Google 登录页](https://accounts.google.com/)。
2. 输入 Gmail 地址，点击“下一步”。
3. 输入密码，再按页面要求完成身份验证。
4. 登录后打开 Gmail，确认可以正常收发邮件。

如果页面要求确认恢复邮箱，请填写账号里已经登记的恢复邮箱，不要临时填写陌生地址。

如果安全活动确实由你发起，可以在 Google 的提示中确认；如果不是你本人操作，应立即拒绝并检查账号安全。

## 三、遇到二次验证怎么办

Google 会根据账号状态提供不同的验证方式。页面显示哪一种，就按对应流程处理。

### Google 提示

已登录该账号的手机可能会收到登录提示。核对设备、时间和大致位置后，再选择“是”。

如果不是你本人发起，选择“否”，随后修改密码并运行[安全检查](https://myaccount.google.com/security-checkup)。

### 身份验证器验证码

打开你设置两步验证时使用的身份验证器，找到对应账号，输入当前显示的 6 位验证码。

验证码会定时更新。快到期时，可以等待下一组数字再输入。

### 扫描二维码

电脑端出现二维码时：

1. 保持二维码页面打开。
2. 用手机相机或 Google App 扫描屏幕上的二维码。
3. 在手机上核对域名和账号。
4. 按手机提示完成验证，再回到电脑继续。

只扫描自己登录页面实时显示的二维码，不要扫描别人发来的截图。

### 手机短信

使用你本人长期控制、能持续接收短信的号码。一次性号码可能在以后登录或找回账号时失效。

不要向任何人转发短信验证码。

### 没有可用的验证方式

点击“尝试其他方式”。如果仍然无法进入账号，使用 [Google 账号恢复页面](https://accounts.google.com/signin/recovery)。

恢复时尽量使用你平时登录过的设备、浏览器和地点，并准确回答页面问题。

## 四、登录后先做安全检查

打开 [Google 安全检查](https://myaccount.google.com/security-checkup)，按页面建议逐项处理。

### 1. 检查已登录设备

进入[设备管理](https://myaccount.google.com/device-activity)，查看最近登录过账号的手机和电脑。

不认识、已丢失或不再使用的设备，应退出登录。

### 2. 设置恢复邮箱

恢复邮箱应当：

- 由你本人长期控制
- 可以正常接收邮件
- 不与当前 Gmail 地址相同

可以在 [Google 账号安全页](https://myaccount.google.com/security)的登录与恢复设置中添加或更新。

### 3. 设置恢复手机号

使用属于你本人、可以长期接收短信的号码。恢复手机号可用于账号找回和异常登录提醒。

修改恢复信息后，Google 可能不会立即信任新信息，这是正常的安全保护。

### 4. 开启两步验证

打开[两步验证设置](https://myaccount.google.com/signinoptions/two-step-verification)，按页面提示开启。

优先使用 Google 提示、通行密钥或安全密钥。身份验证器和备用码可作为后备方式。

备用码必须离线保存，不能放在任何人都能访问的聊天记录或公开网盘中。

### 5. 修改为独立密码

密码应当只用于这个 Google 账号，不要和其他网站共用。

如果怀疑密码泄露，立即修改，不必等待所谓“养号期”。修改后重新检查设备和第三方应用权限。

## 五、怎么正常使用，避免频繁触发验证

网上常说的“养号”，更准确的说法是让账号保持正常、可解释的使用记录。

- 尽量使用自己的常用设备和浏览器。
- 不要短时间内在多台设备上反复登录、退出。
- 不要频繁切换相距很远的登录地区。
- 不要使用共享电脑保存密码或勾选“信任此设备”。
- 不要为了“养号”刻意批量发邮件、点赞或注册大量服务。
- 定期检查恢复信息、登录设备和第三方应用权限。

这些做法不能保证账号永远不触发验证，但能减少异常登录，也方便在需要时证明账号属于你。

## 六、登录异常速查

| 遇到的问题 | 处理方法 |
| --- | --- |
| 忘记密码 | 使用 [账号恢复页面](https://accounts.google.com/signin/recovery) |
| 收不到验证码 | 点击“尝试其他方式”，检查恢复邮箱、Google 提示或备用码 |
| 提示无法确认是你 | 用常用设备、浏览器和地点重新走账号恢复流程 |
| 尝试次数过多 | 停止重复提交，稍后再按官方恢复流程操作 |
| 出现陌生登录 | 拒绝登录、修改密码，并运行安全检查 |
| 手机丢失 | 用备用验证方式进入账号，随后退出丢失设备 |
| 恢复信息刚修改却不能用 | 等待安全保护期，再从常用设备重试 |

Google 不会通过电话、邮件或私信索要你的密码和验证码。验证码只应填写在 Google 官方页面。

## 七、Antigravity 等应用登录注意事项

在 Antigravity 或其他第三方应用里使用 Google 账号时，优先选择官方的“使用 Google 登录”。

授权前检查：

- 浏览器地址是否为 Google 官方域名
- 应用申请了哪些账号权限
- 应用名称是否与你正在使用的软件一致

不要导入来源不明的 Refresh Token，也不要把账号密码交给所谓的账号管理工具。

不再使用某个应用时，可在 [Google 第三方连接管理页](https://myaccount.google.com/connections)撤销访问权限。
