# 插件与技能

扩展 Codex 能力边界——Skill、插件、工作流扩展、Agent 工具、自动化。

## 技能

技能更像把你的固定做事方法保存下来：提示词、流程、规则、素材要求，都可以封装成可复用的 Skill。

| 类型 | 说明 |
|------|------|
| [01 10个Codex项目规范Skills](/plugins/01-top-skills) | 常用 Skill 推荐清单 |
| [02 10个内容创作者必用Skill](/plugins/02-content-creator-skills) | 写作、润色、配图和分发包装技能 |
| [03 8个办公生产力Skill](/plugins/03-codex-practical-plugins) | PPT、表格、视频、设计等高频生产力插件 |

## 插件

插件更像给 Codex 接上外部能力：控制电脑、操作浏览器、连接软件、定时运行任务。

| 插件 | 功能 | 推荐指数 |
|------|------|----------|
| [04 十一个让效率起飞的官方插件](/plugins/04-official-plugins) | 做图、PPT、表格、视频、数据分析和日程管理 | ★★★★★ |
| [05 视频剪辑插件 HyperFrames](/plugins/05-auto-video-edit) | 用 Codex 搭配 HyperFrames 或 Remotion 生成视频 | ★★★★☆ |
