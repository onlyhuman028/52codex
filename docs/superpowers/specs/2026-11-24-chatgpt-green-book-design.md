# 《ChatGPT绿皮书》设计说明

## 目的

把 52codex 项目中面向读者的内容整理为一份可导入飞书、再由飞书导出 PDF 的完整中文 Markdown，方便非技术用户按章节连续学习。

## 收录范围

- 收录首页导读、新手指南、实用技巧、精选案例、插件与技能、资源与 FAQ 等读者内容。
- 唯一明确排除首页“网络热帖”及其数据。
- 排除 AGENTS.md、DESIGN.md、write_rules.md、后台管理页、接口说明、工程配置和构建产物。
- 栏目索引可作为章节导读收录；占位文章保留为“即将上线”条目。
- 内容重复的文章只排一次，但目录应能从相关章节找到。
- 使用工作区当前版本，包括用户尚未提交的内容；不修改任何原始文章。

## 视觉与版式

- 书名：《ChatGPT绿皮书》；作者：清风。
- 封面参考用户提供的蓝皮书：左侧色带、上方细线与英文眉题、大标题、分区导航和版本信息。
- 颜色使用星巴克网站气质的深绿、奶油白、鼠尾草绿和少量暖金；不复制其商标或专有图形。
- 封面不放二维码。正文教学截图中原有且与操作说明相关的二维码可以保留。
- Markdown 内包含文字封面、版权/使用说明、前言、可点击目录和章节分隔；飞书导入后由用户按需设置页面颜色、分页和页码。
- 另附一张深绿、奶油白、鼠尾草绿的封面 PNG 作为可选插图；Markdown 正文即使不插入该图片也完整可读。
- 中文正文清楚、实用、教程化，不营销、不夸大。

## 内容处理

- 保留原文的核心意思、顺序、Prompt、图片、表格和作者署名信息。
- 只做出版层面的机械整理：去除 frontmatter、站内导航、重复 H1、网页专用组件和无效链接。
- 不编造缺失素材，不擅自补写案例、数据、截图或结论。
- 图片按版心缩放，避免裁切；代码和 Prompt 使用独立浅色块，长行自动换行。

## 输出与验收

- 主交付文件：`output/markdown/ChatGPT绿皮书.md`。
- 可选封面图：`output/markdown/ChatGPT绿皮书封面.png`。
- 中间文件统一放在 `tmp/pdfs/`。
- 校验正文文本、目录章节、图片链接、Prompt 围栏、代码围栏和飞书导入易出错的复杂 HTML。
- 已发布的正文图片转换为线上构建产物的 HTTPS 绝对地址；尚未发布的少量本地图片以内嵌 data URI 保留，保证 Markdown 可以作为单文件导入；本地源图片仍需逐一核对存在。

## 考虑过的方案

1. 全仓库逐文件直排：覆盖最全，但会把工程配置和管理内容混入读者手册，放弃。
2. 仅收录核心教程精选：篇幅较短，但不符合用户“除网络热帖外其他都包括”的要求，放弃。
3. 读者内容全收录、工程内容排除：满足范围要求，同时保持成书可读性，采用。
