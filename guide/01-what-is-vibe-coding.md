## 一句话解释

Vibe Coding（氛围编程）= **你用自然语言说你要什么，AI 帮你写代码**。

这个概念是 2025 年 2 月 Andrej Karpathy（OpenAI 联合创始人）提出的。核心思想是：你不需要学编程语言，你只需要学会"说清楚你要什么"。

## 一个类比

想象你以前要装修房子：

- **传统方式**：你自己学木工、水电、瓦工，亲手干
- **请工人**：你画图纸、提需求，工人帮你干
- **Vibe Coding**：你说"我想要一个北欧风的客厅，要有大书架"，AI 帮你从设计到施工全搞定

你需要的不是"怎么砌墙"，而是"知道自己想住什么样的房子"。

## Codex 在这个体系里是什么角色

AI 编程工具很多，Codex 的定位是：

| 工具 | 定位 | 类比 |
|------|------|------|
| ChatGPT | 聊天助手，能写代码片段 | 懂装修的朋友，能给建议 |
| Cursor / Copilot | IDE 内的代码补全 | 你旁边的助手，你写一半它补一半 |
| **Codex** | **项目级编程助手** | **你的施工队，你说需求它交付整个项目** |
| Claude Code | 同类竞品 | 另一支施工队 |

Codex 的特别之处：
- 按**项目**管理，不是一次性对话
- 能操作你的**电脑**（Computer Use）
- 支持**定时任务**（Automations）
- 有**插件和 Skill** 扩展体系
- 能写 AGENTS.md 定义行为规范

## 从 Vibe Coding 到 Agentic Engineering

2026 年 2 月，Karpathy 自己说 Vibe Coding 已经过时了，提出了 **Agentic Engineering**——目标是利用 AI 的杠杆但不牺牲软件质量。

简单说就是一条进化路：

| 阶段 | 你的角色 | Codex 的角色 |
|------|----------|-------------|
| Vibe Coding | 随便说说需求 | 随便写写代码 |
| 有意识的 Prompt | 精确描述需求 | 按要求交付 |
| 工程化 | 写 AGENTS.md、DESIGN.md、Goals | 按规范执行，可复现、可维护 |
| Agentic Engineering | 设计工作系统 | 多 Agent 协作，持续运行 |

**本站的目标就是帮你走完这条路。**
