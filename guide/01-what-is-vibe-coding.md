# Vibe Coding 是什么？不会编程也能用 AI 做项目吗

## 适合谁

这篇适合三类人：

- 听过 Vibe Coding，但不知道它到底是什么意思
- 不会编程，但想用 AI 做网站、表格工具、自动化流程
- 已经在用 ChatGPT，想知道 Codex、Cursor、Copilot 这些工具有什么区别

如果你完全没有技术背景，可以从这篇开始。

## 一句话解释

Vibe Coding（氛围编程）= **你用自然语言说你要什么，AI 帮你写代码**。

它的核心不是“学会一门编程语言”，而是“学会把需求说清楚”。

比如你不需要知道 HTML、CSS、JavaScript 怎么写，只需要能说清楚：

> 我想做一个公司官网，有首页、服务介绍、案例展示、联系方式，整体风格要简洁专业，手机上也能看。

AI 就可以根据你的描述，帮你生成代码、修改页面、运行项目，甚至一步步排查问题。

## 你能做出什么

对非程序员来说，Vibe Coding 最适合从小项目开始：

- 做一个个人主页或公司介绍网站
- 做一个表格整理工具
- 做一个批量生成图片或 PPT 的流程
- 做一个自动搜集资料、整理日报的助手
- 做一个内部使用的小系统，比如招聘管理、客户管理、库存记录

重点是：你不需要一开始就懂代码，但你需要知道自己想解决什么问题。

## 一个类比

可以把 Vibe Coding 想象成装修房子。

| 方式 | 你要做什么 | 结果 |
|------|------------|------|
| 传统编程 | 自己学水电、木工、瓦工 | 全部亲手做 |
| 找程序员 | 你写需求，别人开发 | 等别人交付 |
| Vibe Coding | 你说清楚想要什么，AI 帮你实现 | 边沟通边完成 |

你需要的不是“怎么砌墙”，而是“知道自己想住什么样的房子”。

这也是很多非程序员能开始用 AI 做项目的原因：门槛从“会不会写代码”，变成了“能不能描述清楚目标”。

## Codex 在这个体系里是什么角色

AI 编程工具很多，它们的定位不一样：

| 工具 | 定位 | 更像什么 |
|------|------|----------|
| ChatGPT | 聊天助手，能写代码片段 | 懂技术的朋友 |
| Cursor / Copilot | 编程时的补全助手 | 坐在旁边帮你写代码的人 |
| Codex | 项目级编程助手 | 能接手整个项目的执行助手 |
| Claude Code | 同类项目级工具 | 另一种执行助手 |

Codex 更适合做“项目级任务”，比如：

- 读取一个项目里的多个文件
- 按你的要求修改代码
- 运行命令和测试
- 根据错误信息继续修复
- 通过 AGENTS.md 遵守项目规则
- 配合 Computer Use 操作电脑
- 用 Automations 执行定时任务

所以，本站会更多围绕 Codex 讲“非程序员怎么把想法变成能用的工具”。

## 准备工作

如果你想真正开始实践，建议先准备三件事：

1. 一个明确的小目标  
   比如“做一个个人主页”，不要一开始就说“做一个完整商业系统”。

2. 一个能描述需求的 Prompt  
   先写清楚你要什么页面、什么功能、给谁用、完成后长什么样。

3. 一个项目文件夹  
   Codex 更适合围绕项目工作。把需求、设计、代码都放在同一个文件夹里，后续会更容易维护。

## 操作步骤

你可以按这个顺序开始：

### Step 1：先选一个小项目

不要从复杂系统开始。建议从这些任务里选一个：

- 做一个个人介绍页
- 做一个产品落地页
- 整理一个 Excel 表格
- 生成一份固定格式的日报
- 把一份 Markdown 内容变成网页

### Step 2：用自然语言描述结果

不要只说“帮我做个网站”，而是说清楚：

- 给谁看
- 有哪些内容
- 想要什么风格
- 需要哪些功能
- 做完后怎么判断成功

### Step 3：让 Codex 先给方案

你可以先让 Codex 不写代码，只输出计划：

::: tip Prompt
我不会编程，想用 Codex 做一个个人介绍网站。

请先不要写代码，先帮我拆解：
1. 这个网站需要哪些页面
2. 每个页面应该放什么内容
3. 我需要提前准备哪些素材
4. 第一步应该怎么做

请用新手能看懂的话解释。
:::

### Step 4：再让 Codex 执行

等方案清楚后，再让 Codex 创建文件、写代码、运行项目。这样比一开始直接让它开工更稳。
