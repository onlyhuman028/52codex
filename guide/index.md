# 新手指南

面向完全不会 Codex 的用户。从 0 开始，一步步走到能独立做项目。

## 学习路线图

```
Phase 0  理解概念        什么是 Vibe Coding？Codex 是什么角色？
   ↓
Phase 1  环境搭建        注册账号 → 下载安装 → 熟悉界面
   ↓
Phase 2  上手实战        第一次对话 → 做一个网页 → 学会批注
   ↓
Phase 3  工具扩展        插件 → Skill → 自动化 → 定时任务
   ↓
Phase 4  工程化落地      AGENTS.md → DESIGN.md → Goals → 完整系统
```

## 按顺序学习

| 序号 | 主题 | 你会学到 |
|------|------|----------|
| 01 | [什么是 Vibe Coding](/guide/what-is-vibe-coding) | AI 编程的核心概念，Codex 在体系里的位置 |
| 02 | [注册与订阅](/guide/register) | GPT 注册、Plus/Pro 选择、国内开通方案 |
| 03 | [下载安装 App](/guide/install) | Codex 桌面版安装、首次登录 |
| 04 | [界面全览](/guide/interface) | 对话区、项目区、权限、额度、批注 |
| 05 | [第一个项目](/guide/first-project) | 从第一次对话到完成一个网页 |

::: tip 不用从头看
如果你已经装好了 Codex，直接跳到你需要的章节。每篇都是独立的。
:::
