## 一、为什么是 Codex + HyperFrames？

以前做视频，要找素材、学剪辑、配音乐、加动效，一套下来投入极高。

现在有了 AI：**你描述清楚想要的画面，Codex 负责理解需求、生成代码、组织素材，HyperFrames 或 Remotion 负责渲染成片。**

| 工具 | 作用 | 特点 |
| --- | --- | --- |
| Codex | AI 智能体，理解需求并生成代码 | OpenAI 出品，懂人话，适合把想法落地 |
| HyperFrames | 视频渲染插件 | 听得懂大白话，上手快，适合新手快速出片 |
| Remotion | 代码化视频框架 | 精确到帧控制，适合需要微调的专业用户 |

怎么选？

- 新手首选 **HyperFrames**，成片率更高。
- 需要逐帧控制、复杂动画、组件化工程时，用 **Remotion**。

## 四、提示词专题

写好提示词的核心，是**把你脑里的画面翻译成文字**。

一个好用的视频提示词，至少包含下面这些要素：

| 要素 | 示例 |
| --- | --- |
| 动画/视频类型 | 功能演示、宣传片、影视解说 |
| 时长和画幅 | 15 秒、9:16 |
| 视频目标 | 让观众理解 NVIDIA 在 AI 领域的领导力 |
| 视觉风格 | Apple 风格、极简科技感、电影感 |
| 关键元素 | 必须出现的文字、图片、数据 |
| 动效要求 | 流式打字、淡入淡出、缩放转场 |
| 声音要求 | 配乐风格、有无旁白 |

### 复杂版提示词：科技短片

如果你想要更专业、更可控，可以把提示词写得更像分镜脚本。

::: tip Prompt · Remotion 复杂版
请基于当前 Remotion 项目制作 15 秒科技短片《The Future is Rendering》，1920x1080，30fps。

背景为深蓝黑宇宙流体质感，需要全屏铺满，并加入轻微 zoom、漂移、暗角和蓝色蒙版。背景要明显可见，但不能抢过前景。

整体风格：深蓝黑、蓝紫霓虹、HUD UI、粒子、闪电、科技预告片质感，高级克制。

分镜：

1. 0-3s：中央发光输入框，逐字输入 `Create the future...`，带闪烁光标。
2. 3-6s：大量银蓝色 HUD 方框布满全屏，形成纵深感，依次出现后像被旋涡吸入中心。显示 `Prompt becomes code`。
3. 6-10s：四张科技卡片出现：Design、Motion、Systems、Render。随后卡片逐渐放大、轻微震动，最后像玻璃一样整体破碎，包括边框、面板和文字，碎片飞散消失。显示 `Logic becomes motion.`。
4. 10-13s：一条大的主闪电快速划过，带来横向撕裂感；随后多条闪电布满全屏，最后强闪白。
5. 13-15s：最终标题 `The Future is Rendering`，小字 `Built with Codex + Remotion`，定格收尾。

要求：使用 Sequence、AbsoluteFill、useCurrentFrame、interpolate、spring；组件化实现；保留高级科技感；确保可预览和可渲染。
:::

### 第 4 步：修改与微调

第一版大概率不会完美。不要重开任务，直接告诉 Codex 哪里要改。

- 一次改动不要太多。
- 改完及时预览。
- 截图标注问题位置，比纯文字高效很多。
- 如果某一段效果不好，直接说清楚时间段，比如 `第 6-10 秒卡片太乱，请减少元素数量，突出 Design / Motion / Systems / Render 四个词`。

## 五、进阶技巧：让视频更专业

### 技巧 1：用 Codex 内置 Image Gen 生成素材

触发指令：`$image-gen`

::: tip Prompt
用 $image-gen 的 GPT Image 2 帮我生成一个 iPhone 初代的正面图和背面图。

参考官方产品图，模拟真实质感，最好是透明背景，方便放进视频里做动效。
:::

### 技巧 2：用 Suno 生成背景音乐

网站：[suno.com](https://suno.com)

Suno 每天有免费额度，适合先生成背景音乐，再拖进 Codex 项目里使用。

::: tip Prompt
现代电影预告片风格。

开头用清脆打击乐 + 简约钢琴，逐步加入电子贝斯，高潮加入管弦乐。

整体质感高级、干净，类似苹果发布会能量感，纯音乐，无人声。
:::

旁白配音可以用 Minimax。建议先生成文案，再分段配音，最后让 Codex 按时间轴对齐字幕。

## 六、避坑提醒

### 1. 不要一次给太多指令

把需求拆成 3-5 个步骤，让 Codex 一步步做。哪里出错，哪里改，定位会快很多。

### 2. 复杂动效优先用 Remotion

HyperFrames 听得懂人话，但精确到帧的控制不如 Remotion。如果你要做复杂分镜、品牌级动画、严格时间轴，建议让 Codex 写 Remotion。

### 3. 素材版权一定要注意

生成的图片和音乐一般更适合商用场景，但也要看具体平台规则。不要直接用他人视频截图、影视片段或未授权素材。

### 4. 注意额度消耗

Codex Plus 用户每天有一定免费额度。视频项目因为要生成素材、写代码、反复预览，额度消耗会比普通问答高。重度使用可以考虑 Pro。

## 最后的建议

几天测试下来，我的感受是：**用纯编码形式手搓视频，真的打开了新世界的大门。**

视频创作的门槛又一次被拉低了。我真心建议所有自媒体人、运营人、市场人都花时间学一学。

新手可以先做一个简单的企业或产品介绍，把流程跑通，再逐步加配图、配乐、旁白和复杂动效。
